# Final report template

Lead with the action card.

## Action card

| Field | Required content |
|---|---|
| As of | absolute date, timezone, quote timestamp |
| Security | company, ticker, exchange/board, currency |
| Current action | exactly one of BUY/ADD/HOLD/WAIT/REDUCE/SELL |
| Order now | shares, order type/price condition, or “no order” |
| Entry/no-chase | buy range and maximum chase price |
| Failure/exit | price and fundamental invalidation |
| Target/review | valuation/price target, horizon and next review event |
| Confidence | evidence / thesis / timing separately |

Then report:

1. **Why this action now** — three strongest reasons and the strongest counterargument.
2. **Position math** — current price versus cost, P/L, weight, cash and legal order-unit result.
3. **Research verdict** — business, financials, management/industry, valuation, technical/flow and risks.
4. **Bull vs bear resolution** — evidence that decided the case and unresolved uncertainty.
5. **Scenario valuation** — bear/base/bull assumptions, value, upside/downside and probability caveat.
6. **Discipline table**:

| Trigger | Required action | Quantity | Reason |
|---|---|---:|---|
| Current state | | | |
| Pullback/confirmation | | | |
| Thesis weakens | | | |
| Thesis breaks/red line | | | |
| Valuation becomes excessive | | | |

7. **Unknowns and monitoring** — missing evidence and next filing/catalyst.
8. **Sources** — direct links near claims; include a compact source list only if useful.

For A shares, explicitly print:

- total shares and sellable shares;
- whether today-bought shares are locked by T+1;
- legal minimum/increment for the specific board;
- whether a proposed partial sale is valid;
- what remains after each order.

End with a short risk statement: analysis is probabilistic; price limits, gaps, suspension and liquidity can prevent planned execution.
